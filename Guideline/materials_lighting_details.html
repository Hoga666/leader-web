Glass Token

基于 Figma Glass 参数映射的标准 Token，供开发直接使用，设计中Glass效果应用于导航、参数容器及部分辅助按钮样式中。

Glass-Base

Figma Glass 参数

底层效果，低模糊度高透度，应用于子导航、参数容器和部分辅助按钮样式中。

Color #666666 20%
Light -45° · 80%
Refraction 80
Depth 20
Dispersion 50
Frost 4
Splay 0

CSS Token 映射

backdrop-filter blur(4px) /* Frost 4 */
background linear-gradient(135deg, rgba(255,255,255,0.8) 0%, rgba(255,255,255,0) 40%), rgba(102,102,102,0.2) /* Light -45° 80% + #666666 20% */
border 1px solid rgba(255,255,255,0.25) /* Refraction 80 */
box-shadow 0 20px 40px -8px rgba(0,0,0,0.15) /* Depth 20 */
box-shadow inset 0 0 30px rgba(255,255,255,0.08) /* Dispersion 50 */
border-radius 16px /* Splay 0 */
